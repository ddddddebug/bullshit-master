# Report Writing Guide

## Purpose

Use Report Mode for management updates, project summaries, quarterly reviews, and executive-facing materials.

## Core Structure

Objective or Background

→

Key Progress or Finding

→

Capability or Management Value

→

Risk, Next Action, or Evidence-Based Value Elevation

## Rules

- Lead with the main conclusion or completed result.
- Group related activities into a clear workstream.
- Preserve status distinctions such as completed, in progress, planned, and pending.
- Connect actions to decision support or management value only when supported.
- Use value elevation for recurring updates, feedback-driven iteration, connected deliverables, or reusable outputs.
- Do not turn an isolated task into a strategic transformation claim.

## Example

Before:

整理了Q1策略数据并汇报，根据意见开始做Q2报表。

After:

完成第一季度策略数据的梳理与汇报，并根据反馈意见启动第二季度报表更新，进一步衔接策略复盘与报表迭代，为季度策略跟踪和持续优化提供稳定的信息支持。

## Quality Check

Ensure that the rewrite:

- states progress accurately
- keeps completed and ongoing work distinct
- highlights the management purpose
- avoids vague slogans and unsupported outcomes
