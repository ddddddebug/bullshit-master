# 🧙 Bullshit Master

![MIT License](https://img.shields.io/badge/license-MIT-blue)
![Codex Skill](https://img.shields.io/badge/Codex-Skill-purple)

> Transform ordinary words into professional expressions.

**Bullshit Master** is an AI writing optimization skill that transforms casual, vague, or poorly structured expressions into professional, clear, and value-oriented communication.

It helps users express ideas, contributions, and business value more effectively while preserving the original meaning.

---

# Philosophy

Bullshit Master does not create meaningless jargon.

It helps users:

- express real ideas more clearly
- highlight actual contributions
- communicate value professionally
- improve writing quality without changing facts

> Make your value visible. Don't make your words empty.

---

# Features

## ✨ Professional Writing Optimization

> Transform ordinary words into professional, valuable expressions.

Example:

**Before**

> 这个方案不太行。


**After**

> 当前方案仍存在进一步优化空间，建议结合实际需求及执行条件进行评估调整。


---

## 🚀 Value Enhancement Mode

Transform simple task descriptions into value-oriented expressions.

Example:

**Before**

> 帮助客户开发A卡。


**After**

> 协助客户完成A卡体系建设，填补客户在信用风险量化评估领域的能力空白，建立更加科学的风险识别体系，提升风险管理精细化水平。


Value Enhancement focuses on:

- business value
- project contribution
- capability building
- business impact

---

## 📊 Finance & Risk Writing Mode

Designed for financial and risk management scenarios.

Suitable for:

- risk reports
- credit risk analysis
- model development documents
- financial communication


Example:

**Before**

> 这个模型效果不好，需要调整。


**After**

> 当前模型预测能力仍存在优化空间，建议结合模型区分能力、稳定性指标及业务表现开展进一步优化。


---

## 💼 Business Communication Mode

Improve workplace communication:

- emails
- project updates
- management communication
- presentation materials


Example:

**Before**

> 这个事情进展比较慢，需要大家抓紧一下。


**After**

> 当前项目推进节奏较预期存在一定差距，建议相关团队进一步明确关键时间节点，加强协同推进，确保项目按计划完成。

# Architecture

Bullshit Master is built as a modular AI Skill.

```text

├── SKILL.md
│   Core workflow and behavior definition
│
├── examples/
│   Before-after examples
│
├── references/

│

    Documentation
```

# Installation

Clone this repository:

```bash
git clone https://github.com/你的用户名/bullshit-master.git
```

Copy the skill folder into your Codex skills directory:

```text
~/.codex/skills/
```

Restart Codex and start using:

```text
帮我优化这段文字
```
