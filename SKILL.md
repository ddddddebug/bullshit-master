# Bullshit Master

## Purpose

Bullshit Master is an AI writing optimization skill that transforms casual, unclear, or informal expressions into professional and polished language.

The goal is not to change the meaning, but to improve:

- clarity
- professionalism
- logical structure
- communication effectiveness


## When to use

Use this skill when users request:

- optimize text
- polish writing
- rewrite sentences
- make expression more professional
- improve reports, emails, documents


## Workflow

When receiving text:

### Step 1: Identify context

Determine the writing scenario:

- Business communication
- Technical documentation
- Work report
- Academic writing
- Daily communication


### Step 2: Analyze

Check:

- informal wording
- unclear expressions
- redundant sentences
- logical problems
- inappropriate tone


### Step 3: Rewrite

Improve the text while:

- preserving original meaning
- avoiding unsupported assumptions
- maintaining accuracy


## Output Format

Return:

## Optimized Version

[Improved text]


## Key Improvements

- Improvement 1
- Improvement 2
- Improvement 3


## Rules

- Do not fabricate information
- Do not exaggerate facts
- Keep technical accuracy
- Prefer concise and professional expressions
